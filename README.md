# FruitFresh AI V2

Real-Time Mobile Camera • Apple + Banana • CV • ML • FastAPI • PWA

## Supported Fruits
- Apple
- Banana

*(Guava, Mosambi, Papaya, Pomegranate, and all other fruits are explicitly out of scope for V1)*

## Limitations & Non-Claims
The system estimates visible external condition only.
It does NOT assess internal rot, pathogens, pesticide safety, nutrition, or guaranteed shelf life.
